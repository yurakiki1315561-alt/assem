
# avg5 - 숫자 5개 평균 계산기 (어셈블리)

숫자 5개를 입력받아 평균을 출력하는 x86 32비트 어셈블리 프로그램입니다. C 라이브러리 없이 리눅스 시스템 콜(`int 0x80`)만 사용합니다.

## 환경

- OS: Linux (32비트 바이너리를 실행할 수 있는 x86 / x86-64)
- 어셈블러: [NASM](https://www.nasm.us/)
- 링커: `ld` (GNU binutils)

NASM 설치 (Debian/Ubuntu):

```bash
sudo apt install nasm
```

## 빌드

```bash
nasm -f elf32 avg5.asm -o avg5.o
ld -m elf_i386 avg5.o -o avg5
```

## 실행

```bash
./avg5
```

## 동작 방식

1. `read` 시스템 콜로 한 줄씩 5번 입력을 받습니다.
2. 입력 문자열을 정수로 변환하여 합계(`esi`)에 더합니다.
3. 합계를 5로 나눠 몫(정수부)과 나머지를 구합니다.
4. 나머지 x 2가 소수 첫째 자리입니다. (나머지 / 5 = 나머지 x 2 / 10 이므로 오차 없이 정확합니다.)
5. 결과를 `write` 시스템 콜로 출력하고 `exit`로 종료합니다.

## 제한 사항

- 0 이상의 정수만 지원합니다. 음수와 소수 입력은 처리하지 않습니다.
- 숫자가 아닌 문자를 만나면 그 지점까지만 숫자로 인식합니다. 별도의 오류 메시지는 없습니다.
- 평균은 소수점 첫째 자리까지만 출력합니다.
