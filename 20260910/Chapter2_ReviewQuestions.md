Chapter 2 - x86 Processor Architecture

Review Questions 1-26

교재: Assembly Language for x86 Processors, 7th Edition
Section: 2.8 Review Questions
교재 페이지: 52
PDF 페이지: 87

1번
문제: 32비트 모드에서 ESP 외에 스택의 변수를 가리키는 레지스터는 무엇인가?
답: EBP 레지스터

2번
문제: CPU 상태 플래그를 4개 이상 쓰시오.
답: Carry Flag(CF), Overflow Flag(OF), Sign Flag(SF), Zero Flag(ZF)

3번
문제: 부호 없는 산술 연산의 결과가 대상에 저장할 수 있는 범위를 초과할 때 설정되는 플래그는 무엇인가?
답: Carry Flag(CF)

4번
문제: 부호 있는 산술 연산의 결과가 대상에 저장할 수 있는 범위를 초과하거나 부족할 때 설정되는 플래그는 무엇인가?
답: Overflow Flag(OF)

5번
문제: 32비트 레지스터 피연산자와 REX 접두사를 사용할 때 R8D 레지스터를 사용할 수 있는가?
답: 참

6번
문제: 산술 또는 논리 연산의 결과가 음수가 되었을 때 설정되는 플래그는 무엇인가?
답: Sign Flag(SF)

7번
문제: CPU에서 부동소수점 연산을 수행하는 부분은 무엇인가?
답: FPU(Floating-Point Unit)

8번
문제: 32비트 프로세서에서 각 부동소수점 데이터 레지스터는 몇 비트인가?
답: 80비트

9번
문제: x86-64 명령어 집합은 기존 x86 명령어 집합과 하위 호환되는가?
답: 참

10번
문제: 현재의 64비트 프로세서에서 주소 지정에 64비트 모두를 사용하는가?
답: 거짓

11번
문제: Itanium 명령어 집합은 x86 명령어 집합과 완전히 다른가?
답: 참

12번
문제: 정적 RAM은 일반적으로 동적 RAM보다 저렴한가?
답: 거짓

13번
문제: REX 접두사를 사용할 때 64비트 RDI 레지스터를 사용할 수 있는가?
답: 참

14번
문제: 네이티브 64비트 모드에서는 16비트 실주소 모드를 사용할 수 있지만 virtual-8086 모드는 사용할 수 없는가?
답: 참

15번

답: 거짓

16번

답: 참

17번

답: 거짓

18번
문제: 64비트 모드에서는 최대 8개의 부동소수점 레지스터를 사용할 수 있는가?
답: 참

19번
문제: 버스는 양쪽 끝이 메인보드에 연결된 플라스틱 케이블인가?
답: 거짓

20번
문제: CMOS RAM은 정적 RAM과 동일하며 추가 전원이나 리프레시 없이 값을 유지하는가?

답: 참

답: 거짓

24번

답: 거짓

25번
문제: 어셈블리 언어 프로그램은 어느 수준에서 입출력을 조작할 수 있는가?
답: 모든 입출력 접근 수준에서 가능하다. Level 3 라이브러리 함수, Level 2 운영체제 함수, Level 1 BIOS 함수, Level 0 하드웨어 포트에서 접근할 수 있다.

26번
문제: 게임 프로그램이 사운드 출력을 사운드 카드의 하드웨어 포트로 직접 보내는 경우가 많은 이유는 무엇인가?
답: 하드웨어에 직접 접근하면 장치를 세밀하게 제어할 수 있고 하드웨어가 허용하는 최대 속도로 실행할 수 있기 때문이다.
