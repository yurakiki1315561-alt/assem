2. 일반적인 마이크로컴퓨터 구조

CPU
컴퓨터에서 계산과 논리 연산을 수행하는 핵심 장치이다.

CPU의 주요 구성 요소

레지스터
CPU 내부의 빠른 저장 공간이다.

ALU
Arithmetic Logic Unit
덧셈과 뺄셈 같은 산술 연산과 AND, OR, NOT 같은 논리 연산을 수행한다.

CU
Control Unit
명령어 실행 순서를 제어하고 CPU 내부의 동작을 조정한다.

Clock
CPU 내부의 동작을 일정한 속도로 동기화한다.


3. 버스

버스는 컴퓨터의 여러 구성 요소 사이에서 데이터를 전달하는 통로이다.

주요 버스

Data Bus
CPU와 메모리 사이에서 명령어와 데이터를 전달한다.

I/O Bus
CPU와 입출력 장치 사이에서 데이터를 전달한다.

Control Bus
각 장치의 동작을 동기화하고 제어 신호를 전달한다.

Address Bus
CPU가 접근하려는 메모리 주소를 전달한다.


4. CPU 명령어 실행 과정

CPU는 프로그램의 명령어를 가져오고 해석한 후 실행한다.

기본 과정

1단계
Fetch Instruction
메모리에서 명령어를 가져온다.

2단계
Increment Instruction Pointer
다음 명령어의 위치를 가리키도록 명령어 포인터를 변경한다.

3단계
Decode Instruction
가져온 명령어가 어떤 동작을 의미하는지 해석한다.

4단계
Fetch Operands
명령어 실행에 필요한 피연산자를 레지스터나 메모리에서 가져온다.

5단계
Execute Instruction
CPU가 실제 연산을 수행한다.

6단계
Update Status Flags
연산 결과에 따라 Zero, Carry, Overflow 등의 상태 플래그를 변경한다.

7단계
Store Result
연산 결과를 목적지에 저장한다.

이 과정이 반복되면서 프로그램이 실행된다.


5. 명령어 해석 예시

예를 들어
MOV AX, 1234h

명령어가 여러 바이트로 저장되어 있다면 CPU는 한 바이트씩 가져오면서 명령어를 해석할 수 있다.

첫 번째 바이트를 가져온다.
명령어의 종류를 해석한다.
필요한 피연산자 바이트를 가져온다.
전체 명령어를 완성한다.
명령어를 실행한다.

결과
AX 레지스터에 1234h가 저장된다.


6. 메모리 읽기 과정

CPU가 메모리에서 데이터를 읽을 때의 기본 과정

1. 원하는 메모리 주소를 주소 버스에 전달한다.
2. CPU가 읽기 신호를 보낸다.
3. 메모리가 요청에 응답한다.
4. 데이터 버스를 통해 데이터가 전달된다.
5. CPU가 전달된 데이터를 목적지에 저장한다.


7. 프로그램 실행 과정

프로그램을 실행할 때 운영체제가 수행하는 과정

1. 프로그램 파일을 찾는다.
2. 파일의 크기와 위치 등의 정보를 확인한다.
3. 프로그램을 메모리에 적재한다.
4. 프로그램 실행을 시작한다.
5. 운영체제가 프로세스와 필요한 자원을 관리한다.
6. 프로그램이 종료되면 사용하던 메모리와 자원을 정리한다.


8. 32비트 x86 프로세서

32비트 프로세서는 32비트 데이터를 기본적으로 처리하며 32비트 환경을 제공한다.

주요 실행 모드

Real-Address Mode
메모리와 하드웨어에 직접 접근할 수 있다.
주소 공간은 1MB로 제한된다.

Protected Mode
메모리 보호 기능을 제공한다.
프로세스마다 최대 4GB의 선형 주소 공간을 제공한다.
현대적인 운영체제에서 사용되는 중요한 모드이다.

Virtual-8086 Mode
보호 모드 안에서 real-address 모드의 프로그램을 실행할 수 있도록 하는 방식이다.
가상 머신 환경에서 여러 프로그램을 실행할 수 있다.

System Management Mode
전원 관리와 시스템 보안 등의 기능을 수행한다.

13. EIP 레지스터

EIP는 Instruction Pointer이다.

역할
CPU가 다음에 실행할 명령어의 주소를 저장한다.

명령어가 순서대로 실행되면 EIP가 다음 명령어를 가리키도록 변경된다.

JMP, CALL, RET, 조건부 분기 명령어 등을 사용하면 EIP가 다른 위치로 변경될 수 있다.


14. EFLAGS 레지스터

EFLAGS에는 CPU의 상태를 나타내는 여러 플래그가 들어 있다.

주요 상태 플래그

Carry Flag
CF
부호 없는 연산에서 결과가 저장 범위를 넘어갈 때 사용한다.

Overflow Flag
OF
부호 있는 연산에서 결과가 표현 범위를 넘어갈 때 사용한다.

Sign Flag
SF
연산 결과가 음수임을 나타낸다.

Zero Flag
ZF
연산 결과가 0일 때 설정된다.

Auxiliary Carry Flag
AC
하위 4비트에서 상위 4비트로 자리올림이 발생했는지 나타낸다.

Parity Flag
PF
결과에 포함된 1의 개수가 짝수인지 나타낸다.

상태 플래그는 CPU의 연산 결과를 확인하는 데 사용된다.

총 8개

FPU Data Pointer

18. 64비트 x86-64 프로세서

x86-64는 64비트 정수 피연산자와 주소 공간을 지원한다.

주요 특징

64비트 레지스터
64비트 정수 데이터를 처리할 수 있다.

추가 범용 레지스터
기존 x86보다 더 많은 범용 레지스터를 제공한다.

64비트 주소
매우 큰 가상 주소 공간을 사용할 수 있다.

48비트 물리 주소 공간
수업 자료에서는 최대 256TB의 RAM을 지원하는 예를 제시한다.

하위 호환성
기존 x86 명령어 집합과의 호환성을 유지한다.


19. 64비트 프로세서의 동작 모드

Compatibility Mode
기존 16비트와 32비트 프로그램을 실행할 수 있다.
기존 프로그램을 다시 컴파일하지 않고 실행할 수 있도록 한다.

64-Bit Mode
64비트 명령어 피연산자와 64비트 주소 공간을 사용할 수 있다.
64비트 응용 프로그램을 위한 모드이다.

26. 메모리 종류

ROM
읽기 전용 메모리
영구적으로 저장된 내용을 유지한다.

EPROM
자외선을 이용하여 내용을 지운 후 다시 프로그램할 수 있다.

DRAM
메인 메모리로 사용된다.
지속적인 리프레시가 필요하다.

SRAM
고속 캐시 메모리에 사용된다.
DRAM과 달리 일반적으로 리프레시가 필요하지 않다.

VRAM
화면에 표시되는 영상 데이터를 저장하는 데 사용된다.

CMOS RAM
시스템 설정 정보를 저장하며 배터리로 유지된다.


27. 입출력 시스템

I/O
Input and Output
컴퓨터와 외부 장치 사이에서 데이터를 주고받는 과정이다.

입출력은 여러 계층을 통해 이루어질 수 있다.

28. 입출력 접근 수준

Level 3
Library Function
일반적인 텍스트와 파일 입출력 등에 사용된다.

Level 2
Operating System Function
운영체제의 기능을 이용한다.

Level 1
BIOS Function
장치와 관련된 기능을 직접 제어하는 데 사용할 수 있다.

Level 0
Hardware Port Control
특정 장치의 하드웨어 포트를 직접 제어한다.

낮은 수준으로 내려갈수록 하드웨어에 직접적으로 가까워진다.


29. 장치 드라이버

장치 드라이버는 운영체제와 하드웨어 장치 사이에서 통신을 담당한다.

기본 과정

1. 운영체제가 장치에 대한 요청을 보낸다.
2. 드라이버가 요청을 받는다.
3. 드라이버가 장치의 데이터를 읽거나 명령을 전달한다.
4. 필요한 펌웨어 코드를 실행한다.
5. 데이터를 운영체제에 전달한다.

장치 드라이버를 통해 운영체제가 다양한 하드웨어 장치를 사용할 수 있다.


30. 화면에 문자열을 출력하는 과정

수업 자료에서는 문자열 출력이 여러 단계로 이루어지는 과정을 설명한다.

응용 프로그램
→ 라이브러리 함수
→ 운영체제 함수
→ BIOS 함수
→ 비디오 컨트롤러
→ 화면

각 단계가 다음 단계에 필요한 작업을 요청하는 방식이다.


31. 2장 핵심 정리

CPU는 레지스터, ALU, 제어 장치, 클록 등을 이용하여 명령어를 실행한다.

CPU와 메모리 및 입출력 장치는 버스를 통해 연결된다.

명령어 실행은 가져오기, 해석, 피연산자 가져오기, 실행, 상태 플래그 갱신, 결과 저장 등의 과정으로 이루어진다.

EIP는 다음에 실행할 명령어의 위치를 가리킨다.

EFLAGS는 CPU의 상태와 제어 정보를 저장한다.

32비트 x86에는 Real-Address Mode, Protected Mode, Virtual-8086 Mode 등의 실행 모드가 있다.

64비트 x86-64는 64비트 레지스터와 더 많은 범용 레지스터, 큰 주소 공간을 제공한다.

REX 접두사는 64비트 피연산자와 추가 레지스터를 사용할 수 있도록 한다.

메인보드는 CPU, 메모리, 칩셋, 저장 장치, 입출력 장치, 확장 슬롯 등을 연결한다.

DRAM, SRAM, ROM, EPROM, VRAM, CMOS RAM은 각각 용도와 특성이 다르다.

입출력은 라이브러리, 운영체제, BIOS, 하드웨어 등의 여러 수준에서 접근할 수 있다.

어셈블리 언어를 공부하려면 CPU 구조와 레지스터, 메모리, 버스, 입출력 구조를 함께 이해하는 것이 중요하다.
